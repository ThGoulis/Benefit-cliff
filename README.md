# Χάρτης Εισοδήματος

Ο πλήρης χάρτης του εισοδήματός σου — μισθός και επιδόματα μαζί, σε ένα διάγραμμα.

Ζωντανό: **https://thgoulis.github.io/Benefit-cliff/**

## Τι κάνει

Δείχνει πώς αλλάζει το **πραγματικό καθαρό διαθέσιμο εισόδημα** ενός νοικοκυριού (μισθός + επιδόματα) καθώς αυξάνεται ο μεικτός μισθός — και εντοπίζει αυτόματα τα σημεία όπου η αύξηση μισθού προκαλεί **απώλεια επιδόματος** ("γκρεμός επιδομάτων").

Περιλαμβάνει ένα **executive summary** (πρόταση-insight, καθαρός μισθός/επιδόματα/σύνολο, ρίσκο γκρεμού, απόσταση από τον επόμενο), κουμπιά **"τι θα γινόταν με αύξηση"** (+100/+200/+500/+1.000€) για γρήγορη εξερεύνηση, και μια λεπτή γραμμή κολλημένη πάνω με το header που δείχνει ζωντανά το σύνολο στο ελάχιστο εισόδημα, χρωματισμένη ανάλογα με το ρίσκο γκρεμού.

Μοντελοποιεί:
- Καθαρό μισθό (σύστημα 14 μισθών, ΕΦΚΑ, προοδευτική κλίμακα φόρου ανά ηλικία, φορολογική έκπτωση — οποιοσδήποτε αριθμός παιδιών)
- Ελάχιστο Εγγυημένο Εισόδημα (ΕΕΕ)
- Επίδομα Παιδιού (Α21)
- Επίδομα Ενοικίου
- Κοινωνικό Οικιακό Τιμολόγιο (ΚΟΤ) στο ρεύμα
- Περιουσιακά κριτήρια (ακίνητη περιουσία, καταθέσεις) που μπλοκάρουν ΕΕΕ/ενοίκιο/ΚΟΤ ανεξάρτητα από το εισόδημα
- Οποιοδήποτε νοικοκυριό: διαλέγεις αν υπάρχει σύζυγος/σύντροφος και πόσα παιδιά (0-5+) — η μονογονεϊκή κατάσταση αναγνωρίζεται αυτόματα, με ειδικούς κανόνες σε ΕΕΕ/Α21/ενοίκιο (βλ. [TECHNICAL.md](./TECHNICAL.md))

Αδελφό project του [Οικονομικού Σχεδιασμού](https://github.com/ThGoulis/personal-finance-dashboard) — επαναχρησιμοποιεί την ίδια μισθολογική λογική.

## Χρήση

Απλά άνοιξε το `index.html` σε browser, ή επισκέψου το ζωντανό demo παραπάνω. Καμία εγκατάσταση, καμία εξάρτηση.

1. Σύρε το slider για το μεικτό μηνιαίο εισόδημα (ή δοκίμασε τα κουμπιά "τι θα γινόταν με αύξηση")
2. Δες την καμπύλη, τα σημάδια γκρεμού (⚠), και το executive summary από κάτω
3. Στην ενότητα "Στοιχεία σου" διαλέγεις αν έχεις σύζυγο/σύντροφο, πόσα παιδιά, ηλικία(-ες), περιουσία και κατανάλωση ρεύματος

## Τοπική εκτέλεση

```bash
git clone https://github.com/ThGoulis/Benefit-cliff.git
cd Benefit-cliff
# άνοιξε το index.html απευθείας, ή:
python3 -m http.server
```

